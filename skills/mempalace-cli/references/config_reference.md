# MemPalace Configuration Reference

## Config File: `~/.mempalace/config.json`

Priority order: **env vars > config.json > defaults**

### Full Schema

```json
{
  "palace_path": "~/.mempalace/palace",
  "collection_name": "mempalace_drawers",
  "embedding": {
    "model": "BAAI/bge-m3",
    "device": "cpu",
    "dtype": "float32"
  },
  "llm": {
    "api_key": "sk-xxx",
    "base_url": "https://api.openai.com/v1",
    "model": "gpt-4o"
  }
}
```

### Field Descriptions

| Field | Default | Description |
|---|---|---|
| `palace_path` | `~/.mempalace/palace` | ChromaDB persistence directory |
| `collection_name` | `mempalace_drawers` | ChromaDB collection name |
| `embedding.model` | ChromaDB default | sentence-transformers model name |
| `embedding.device` | `cpu` | `cpu`, `cuda`, or `auto` |
| `embedding.dtype` | `float32` | `float32`, `float16`, or `bfloat16` |
| `llm.api_key` | — | OpenAI-compatible API key |
| `llm.base_url` | OpenAI endpoint | API base URL (use for DeepSeek, local LLMs, etc.) |
| `llm.model` | — | Model name for `init --llm` |

## Environment Variables

All env vars have highest priority, overriding both config.json and defaults.

| Variable | Overrides |
|---|---|
| `MEMPALACE_PALACE_PATH` | `palace_path` |
| `MEMPALACE_COLLECTION_NAME` | `collection_name` |
| `MEMPALACE_LLM_API_KEY` | `llm.api_key` |
| `MEMPALACE_LLM_BASE_URL` | `llm.base_url` |
| `MEMPALACE_LLM_MODEL` | `llm.model` |
| `MEMPAL_DIR` | Source dir for auto-mine in hooks |
| `ORT_DISABLE_COREML` | Disable CoreML on Apple Silicon (auto-set) |
| `MEMPALACE_SOURCE_DIR` | Default source dir for `split` command |

## Recommended Embedding Models

| Model | Install | Best For |
|---|---|---|
| ChromaDB default (all-MiniLM) | none | English, quick start |
| `BAAI/bge-m3` | `pip install "mempalace[chinese]"` | Multilingual, Chinese |
| `BAAI/bge-small-zh` | `pip install "mempalace[chinese]"` | Chinese, lightweight |
| `Qwen/Qwen3-Embedding-4B` | `pip install "mempalace[qwen]"` | Best multilingual quality |

To use a custom model, add to `~/.mempalace/config.json`:
```json
{
  "embedding": {
    "model": "BAAI/bge-m3",
    "device": "cpu"
  }
}
```

## `mempalace.yaml` — Project Routing File

Generated by `mempalace init` in the project directory. Controls how files are routed
to rooms during mining.

### Format

```yaml
wing: my_project
rooms:
  frontend:
    keywords: [react, component, css, ui, tsx, jsx]
    paths: [src/components/, src/pages/]
  backend:
    keywords: [api, server, django, fastapi, routes]
    paths: [backend/, api/]
  documentation:
    keywords: [readme, guide, tutorial, docs]
    paths: [docs/, README.md]
  tests:
    keywords: [test, spec, pytest, jest]
    paths: [tests/, __tests__/]
```

### Fields

| Field | Description |
|---|---|
| `wing` | Wing name for all files in this project |
| `rooms.<name>.keywords` | File content keywords that route to this room |
| `rooms.<name>.paths` | File paths (relative) that always go to this room |

Files not matching any room go to a default `general` room.

## Identity File: `~/.mempalace/identity.txt`

Plain text. Loaded as Layer 0 (L0) context (~100 tokens) at every wake-up.

Example:
```
I am Atlas, a personal AI assistant for Alice.
Traits: warm, direct, remembers everything.
People: Alice (creator), Bob (Alice's partner), Riley (daughter, age 8).
Project: mempalace — AI memory system, Python, ChromaDB.
```

---

## Wing / Room Name Rules

Valid names must:
- Start with a letter, digit, underscore, or CJK character
- Contain only: letters, digits, `_`, ` `, `.`, `'`, `-`
- Be ≤ 128 characters
- Not contain `..`, `/`, `\`, or null bytes

Invalid: `../../etc`, `my/room`, names with special chars like `@`, `#`, `!`
